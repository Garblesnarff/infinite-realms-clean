# Campaign Metadata

`campaign.yaml` is the proposed future per-package source of truth. The schema separates writing, asset, legal, ingestion, and release state instead of encoding all state in a directory name.

Readiness uses 100 points: premise 10; structure 15; NPC/faction/location coverage 10; mechanics 10; endings/replayability 10; coherence 10; originality/IP safety 10; visual direction 5; existing assets 10; ingestion readiness 10.

Confidence remains High, Medium, or Low and records how much evidence was inspected. Document length alone never establishes quality or readiness.
